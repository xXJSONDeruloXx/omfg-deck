# OMFG Deck — Plugin Defaults

This directory holds static assets bundled with the plugin zip.

## omfg-live.toml (written at install time)

The plugin writes a default `omfg-live.toml` to `~/.config/omfg/omfg-live.toml`
on first install. The layer hot-reloads this file every ~250 ms.

Default values mirror the OMFG project defaults:
  OMFG_LAYER_MODE = "reproject-blend"
  OMFG_DEBUG_VIEW = "off"
  OMFG_REPROJECT_SEARCH_RADIUS = 2
  OMFG_REPROJECT_PATCH_RADIUS = 1
  OMFG_MULTI_BLEND_COUNT = 2
  OMFG_ADAPTIVE_MULTI_TARGET_FPS = 120
  (... see plugin UI for all fields)

## omfg-wrapper.sh (written at install time)

The plugin writes `~/.config/omfg/omfg-wrapper.sh` as an optional launch wrapper.
Use as Steam Launch Option:
  /home/deck/.config/omfg/omfg-wrapper.sh %command%

Or use the raw env-var form (shown in plugin UI clipboard button):
  ENABLE_OMFG_RUST=1 OMFG_HOT_CONFIG_PATH=/home/deck/.config/omfg/omfg-live.toml %command%
